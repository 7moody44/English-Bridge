# Project Instructions

## Git workflow
- After completing any task that changes files (code, assets, config), commit and push to `origin` (GitHub: 7moody44/English-Bridge).
- Commit message style: short, descriptive (e.g. "fix in otp", "add otp fallback code when email send is slow").
- Run `git status` / `git diff` before committing to review what is being staged.
